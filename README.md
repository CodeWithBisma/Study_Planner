# AI Study Planner

A desktop-based study planner built with Python and Tkinter to help students organize and manage study tasks effectively. It provides secure authentication, task creation, deadline tracking, automated scheduling, and productivity monitoring to improve study planning and time management.

---

## Features
- User authentication with secure password hashing  
- Add, view, and manage study tasks  
- Track tasks with subject, topic, deadline, estimated time, and priority  
- Automatically generate a study schedule based on deadlines and priorities  
- View productivity statistics by priority levels  
- Persistent storage of user data using JSON  

---

## Technology Stack
- Python 3  
- Tkinter (GUI framework)  
- JSON (local data storage)  
- Hashlib (password security)
